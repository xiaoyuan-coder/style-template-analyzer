# 风格模板运行提示词撰写规范

本规范定义 `promptTemplate` 的生产格式。它面向“用户上传一张图 + 一份模板提示词”的直接生图请求，服务 Memebuy 风格模板的 Approved After 复现、跨图迁移和批量交付。

OpenAI 官方图像提示指南建议生产提示词保持稳定顺序，使用短标签或换行拆分复杂请求，并明确构图、位置、保持项、改变项和排除项。本规范在此基础上增加 Memebuy 所需的内容归属、结构机关、跨图角色映射和动态回放门禁。官方依据见 [GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)。

## 1. 运行边界

- 模型图片输入固定为用户上传图 `[source]`，数量为 1。
- `cover`、Approved After、Before/After 对照图、GoodCase 和分析素材只参与离线编译与评测。
- `promptTemplate` 是模型运行时看到的完整指令，使用“用户上传图”指向 `[source]`。
- 审计字段、证据摘要、内部标签和模板生产过程留在内部合同中。
- Approved After 是目标视觉权威；提示词需要复现其中可迁移的关系与成像机制。

完成条件：生成请求只包含 `[source] + promptTemplate`，回执中的提示词 SHA 与交付 JSON 完全一致。

## 2. 先确定提示词档位

每份模板选择一个主档位，混合模板使用最高风险档位。

| 档位 | 主要变化 | 写作重点 |
| --- | --- | --- |
| `S1 表面风格` | 线条、色彩、笔触、纹理、明暗 | 保持原构图，完整描述全图成像语言 |
| `S2 形态材质` | 主体形态、工艺、体积或材质 | 明确形态权限、身份锚点和材质覆盖范围 |
| `S3 结构重构` | 分格、折叠、解构、多视角、负形、路径或尺度派生 | 完整描述区域骨架、内容职责、层级和必现机关 |
| `S4 视觉系统` | UI、档案、图鉴、信息板或固定容器 | 明确模板常量、容器数量、信息层级和允许文字 |

`S3` 和 `S4` 必须使用全部九段，并写出可量化的空间关系。`S1` 和 `S2` 也保留九个标题，每段可以只写一句。

完成条件：档位能够解释 Approved Before 到 Approved After 的最大视觉变化，且所有次级变化已经分配到九段中的明确位置。

## 2.1 先编译转换内核

九段成文前先完成 `X 图形语言 × Y 空间语法 × B 内容绑定 × C 边界策略`：

- X 只描述线条、色彩、材质、纹理、明暗和媒介覆盖；
- Y 描述分区、重排、重复、切片、路径、遮挡、尺度和阅读顺序；
- B 声明每个区域或派生元素从用户图的哪个视觉角色取得内容；
- C 声明画布触边、裁切、闭合、安全边距和越界方式。

半抽象与抽象模板还要写清 `abstractionSource → abstractionOperator → abstractOutput → figurativeBudget`。这些内部变量编译成可见动作后进入九段，运行提示词不保留变量名。

## 3. 九段运行结构

按下列固定顺序编写。目标长度为 450–1100 个中文字符，硬上限 1200。

### 3.1 任务

说明内容依据、完整重绘动作、目标图像类型和成图用途。使用一句话。

```text
任务：
以用户上传图为唯一内容依据，从零完整重绘整张图像，生成一幅可直接用于服装印制的<目标图像类型>。
```

### 3.2 保留

列出输出仍需可辨认的内容不变量：主体选择、身份、基础实例数量、识别特征、服装、配饰、手持物、关联物和关键关系。只保留与本模板实际相关的项。

```text
保留：
保留全部显著主体并与用户图逐一对应；保持身份、主识别特征、服装、配饰、手持物及关键关系。基础主体保持原数量。
```

当模板授权主主体提取、实例派生或形态变化时，在本段保留仍然成立的身份锚点，把变化权限写入下一段。

### 3.3 变换权限

用直接动词列出允许改变的维度：形态、动作、视角、实例派生、环境、裁切、比例、遮挡和构图。每个被改变的维度都需要获得明确权限。

```text
变换权限：
允许重建环境并重组构图；允许从同一主体派生一个局部特写。主呈现保持原身份，派生内容持续归属于该主体。
```

表面风格模板写明只改变绘制语言和材质表现，同时保持主体形态、姿态、视角、环境和主要构图。

### 3.4 核心效果

写出 1–3 个决定模板身份的必现机关。每个机关使用“来源角色 + 变换动作 + 可见结果”的完整句式。

```text
核心效果：
把用户图中的<来源角色>经过<变换动作>形成<可见结果>；该结构必须在缩略图尺寸下清楚可读。
```

核心机关具有最高视觉优先级。颜色、纹理和装饰不能替代核心机关。缺少任一核心机关时，本次生成判定失败。

### 3.5 空间结构

把画面写成可执行的空间蓝图，至少覆盖适用项：

- 画幅方向与宽高比策略；
- 区域数量、形状和阅读顺序；
- 区域在画布中的位置与面积范围；
- 主体和局部派生的相对尺度；
- 前后层级、遮挡、相交、跨界和留白；
- 路径的起点、转折点和终点；
- 元素触边、闭合或保留安全边距的规则。

使用相对比例和范围，例如“占画面 45%–60%”“左上至右下”“前层覆盖后层约四分之一”。像素尺寸只用于固定画幅模板。

```text
空间结构：
中央设置一个占画面45%–60%的旋转菱形主区；四条宽白斜边从菱形顶点延伸到画布边缘，分出四个面积不同的角区。中央主区位于最上层，四角内容在斜边下方裁切。
```

### 3.6 内容映射

逐区说明用户图内容如何进入空间骨架。使用通用视觉角色，保留来源归属。

常用来源角色包括：

- 主主体、主识别区域、完整轮廓；
- 最大色面、最长窄长轮廓、最大弧形轮廓；
- 接触部位、相向间隙、承托面、中央开口；
- 前景、中景、远景、主要环境边界；
- 方向线索、高光切点、重复纹理和负形。

每个角色声明一种绑定方式：

- `必选角色`：核心机关依赖该角色；从用户图中选择最接近的可见内容承担它。
- `自适应角色`：形状、方向、数量和间距跟随用户图重新求值。
- `辅助角色`：缺失后可以省略，且不会导致核心效果消失。

核心机关不得绑定为可省略的辅助角色。找不到可跨输入替代的必选角色时，该模板需要收窄适用输入范围或返工核心设计。

```text
内容映射：
中央主区放置一次完整主主体；四个角区分别使用用户图中四类不同的可见局部，优先选择关联物、环境结构、最大色面和主体边缘细节。四角只呈现局部，不复制完整主体或完整脸。
```

### 3.7 视觉风格

使用像素可观察语言覆盖：媒介与底材、形体概括、线条与边缘、笔触与纹理、色彩角色、明暗级数、空间平面化方式和全图覆盖。

将内部风格标签展开。例如把“复古漫画孔版”展开为“深色粗墨线、高明度有限色平涂、稀疏圆点网纹、轻微套色偏移和纸面留白”。

视觉风格段专注成像语言。分格、折叠、路径、实例派生和内容职责写入前四个执行段。

### 3.8 完成判据

列出 3–5 个模型可以在最终图中直接检查的正向条件。条件对应 Approved After 的核心效果、空间结构、内容映射和成像语言。

```text
完成判据：
最终图必须同时出现中央菱形、四条白色斜分割和四个内容职责不同的角区；完整主主体只在中央出现一次；缩略图下仍能先读到菱形骨架，再读到四角回返。
```

完成判据承担生成前的自检职责，也直接转化为动态回放评分项。避免使用“高级、好看、有设计感、还原效果”等无法观察的词。

### 3.9 限制

只保留本模板真实发生过的漂移风险。先写目标边界，再写必要排除项。

```text
限制：
画面只包含用户图内容、模板固定结构和已授权派生。不要新增人物、动物、物件、关系、品牌、可读文字或界面；不要保留照片像素、摄影景深、镜头光照或滤镜叠加痕迹。
```

普通服装图案排除连接线、定位点、刻度、图例、编号和分析框。`S4 视觉系统` 只开放合同明确列出的固定组件和文字。

## 4. 空间蓝图最低信息量

`S3 结构重构` 和 `S4 视觉系统` 的提示词必须回答以下问题：

1. 画布被分成几块？
2. 每块是什么形状，位于哪里，占多大范围？
3. 每块放什么来源内容，承担什么观看职责？
4. 完整主体、局部派生和环境分别出现几次？
5. 哪一层在前，哪里遮挡、相交、跨界或留白？
6. 哪个关系是模板必现机关？
7. 缺少哪个可见条件就应判定失败？

任何一项只能从模板名称或抽象概念中猜测时，空间蓝图仍未完成。

## 5. 通用性规则

### 5.1 保留机制，替换案例物象

Before 中的具体人物、物种、道具和场景只用于识别视觉职责。运行提示词使用视觉角色承载同一机制。

示例：

- “雨伞决定最外层等高线”改写为“用户图中的最大闭合轮廓决定最外层等高带”。
- “手势投出侧脸影子”改写为“离光源最近且轮廓最清晰的前景局部投出大阴影，阴影负形重构同一主体的识别侧影”。
- “车厢拆成四层”改写为“将前景承托层、主体层、主要环境结构层和远景层拆成四块错位剖片”。

### 5.2 核心角色必须有替代策略

必选角色缺失时按以下顺序处理：

1. 在用户图中选择形态或关系最接近的可见内容；
2. 使用主主体自身的轮廓、负形、色面或方向承担角色；
3. 收窄模板支持的输入范围并在评测集中覆盖该范围；
4. 核心机关仍无法成立时，模板返回编译阶段重新设计。

辅助装饰可以省略。核心效果持续必现。

### 5.3 实例与局部派生

- 基础实例数量默认与用户图逐一对应。
- 分格、多视角、局部放大和姿态回声属于派生实例，需要持续归属于原主体。
- 每个区域写明使用完整主体、识别局部或环境局部。
- 提示词明确完整主体出现次数，防止每个分区都生成完整复制体。

## 6. 句子写法

- 使用动作动词开头：设置、拆分、放置、折回、延展、裁切、覆盖、连接、重组。
- 一句只承担一个视觉决定；同义决定只保留一次。
- 使用可见名词：菱形、斜边、色带、空气缝、粗网点、负形侧影。
- 使用范围控制比例，避免不可执行的精密坐标。
- 正向描述目标画面，必要限制放在末段。
- 高层形容词需要展开成形状、线条、颜色、材质、明暗或空间关系。
- 关键结构在“核心效果、空间结构、完成判据”中分别承担定义、执行和验收职责；三处信息互补，不重复长句。

## 7. 静态门禁

每份新提示词同时满足：

- 九个标题各出现一次，顺序固定且内容非空；
- 以用户上传图为内容依据，并要求全图完整重绘；
- 保留项与变换权限无冲突；
- 每个必现机关同时具备来源角色、变换动作和可见结果；
- `S3/S4` 通过空间蓝图七问；
- 每个画布区域都有内容职责；
- 基础实例和派生实例数量明确；
- 核心角色均有跨输入替代策略；
- 完成判据可直接从最终图观察；
- 不含案例专属物象、内部合同词、图片序号和悬空指代；
- 长度为 120–1200 字，推荐 450–1100 字。

静态门禁只允许提示词进入真实回放，不能授予 `pass` 或正式化状态。

## 8. 动态门禁

### 8.1 原始回放

使用最终提示词和对应 Approved Before 单图生成，Approved After 只在生成完成后参与评分。回执冻结提示词 SHA、Before SHA、生成结果 SHA、图片输入数量和 After 未作为输入。

每份模板的评分权重写入复现合同，总分 100。推荐基线：

- 核心效果：40；
- 空间结构：20；
- 内容映射与实例：15；
- 主体身份与关系：10；
- 视觉风格：10；
- 画幅与印制闭合：5。

目标为总分至少 95，任何必现机关缺失、提示词 SHA 不一致、输入超过一张或 After 参与输入时直接失败。

### 8.2 换图迁移

至少使用两张在主体类别、方向或环境复杂度上不同的新图。核心效果、空间骨架和视觉风格继续出现，案例物象不泄漏，用户主体与关键关系保持清楚。

`S3/S4` 高风险模板至少重复运行两次。结构不稳定时继续修订提示词，不能用挑选偶然成功结果代替稳定性验证。

## 9. 标准模板

```text
任务：
以用户上传图为唯一内容依据，从零完整重绘整张图像，生成一幅可直接用于服装印制的<目标图像类型>。

保留：
<主体选择、身份锚点、基础实例、服装配饰、关联物和关键关系>。

变换权限：
<允许改变与必须保持的形态、姿态、视角、环境、实例、裁切和构图维度>。

核心效果：
<必现机关一：来源角色 + 动作 + 可见结果>。<必现机关二>。

空间结构：
<画幅策略、区域数量、形状、位置比例、阅读顺序、尺度、层级、遮挡、路径和边界>。

内容映射：
<每个区域绑定的用户图角色、完整/局部类型、实例次数和角色替代策略>。

视觉风格：
<媒介、形体、线条、笔触、纹理、色彩、明暗、空间和平面覆盖>。

完成判据：
最终图必须同时满足<三至五个可观察条件>。

限制：
画面只包含用户图内容、模板固定结构和已授权派生。<本模板特有漂移边界>。
```

## 10. 完成定义

一份提示词规范化完成需要同时具备：

1. 九段运行提示词；
2. 与九段逐项对应的复现合同；
3. 通过静态门禁；
4. 通过 Approved Before 原始回放；
5. 通过跨图迁移；
6. 生成回执与交付 JSON 的提示词 SHA 一致。

前五项中的任何一项仍为 pending 时，该 revision 保持“运行待复现”，不进入正式交付。
