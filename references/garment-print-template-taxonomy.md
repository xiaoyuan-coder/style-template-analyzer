# 服装印制图案模板分类与适配

前端只展示一个用户可见分类，内部使用多轴记录生产与验收事实。单层分类服务模板浏览，多轴字段服务提示词编译、质量评测和印制判断。

## 1. 用户可见分类 `userFacingCategory`

每个模板只选择以下九类中的一个：

| 分类 | 唯一判定标准 |
| --- | --- |
| `手绘` | 水彩、蜡笔、彩铅、粉彩、墨线或手工绘画笔触主导 |
| `版印` | 孔版、丝印、木刻、干刻、网点、阈值、压印或油墨纸纹主导 |
| `漫画` | 漫画、动漫或电视卡通的造型、线稿和明暗语言主导 |
| `像素` | 像素栅格、低位色抖动、字符密度或点阵重建主导 |
| `材质` | 主体和环境被重塑为黏土、针毡、刺绣、陶瓷、金属或体素等实体材料 |
| `图形` | 色块、轮廓、渐变、几何、剪影、等高线或伪彩系统主导 |
| `拼贴` | 多块素材、纸片、贴纸或展示模块通过裁切、叠压和并置形成整体 |
| `分镜` | 多格或多联画直接承担叙事、节奏或多视角呈现 |
| `界面` | CRT、掌机、街机、窗口或控件系统成为核心审美结构 |

按以下顺序完成唯一归属：

1. 界面系统成为第一视觉特征时归入 `界面`。
2. 多格叙事或多视角成为第一视觉特征时归入 `分镜`。
3. 装饰拼贴、贴纸组或模块并置成为第一视觉特征时归入 `拼贴`。
4. 其余模板按最影响最终像素的成像机制归入手绘、版印、漫画、像素、材质或图形。

人物、宠物、商品、风景等输入内容不参与分类。复古、双色、颗粒、错位、透明底等进入名称或内部分析。

### 公开名称

- 使用“固定关键参数 + 核心机制或结构”。
- 控制在 3–6 个字符，批次内保持唯一。
- 固定且显著的颜色、材质或结构进入名称，例如 `水青阈值`、`粉彩孔版`、`羊毛针毡`、`CRT界面`。
- 次要纹理、完整机制和适用主体进入描述、提示词与内部分析。
- 自动泛化产生不同固定配色时，每套配色形成独立模板、名称、封面和验收记录。

## 2. 成图产品轴 `designProduct`

这是一级分类，回答“用户最终会得到什么样的可印制设计”。

| 值 | 定义 | 默认适配 |
| --- | --- | --- |
| `artwork` | 单幅完整图案；主体与场景形成一个连续视觉整体 | 推荐 |
| `emblem` | 徽章、贴纸、章牌、轮廓剪影等边界明确的集中图案 | 推荐 |
| `pattern` | 可平铺或重复的满版纹样 | 推荐 |
| `panel-sequence` | 漫画分格、接触表、多联画；每格直接承担叙事或审美 | 有条件推荐 |
| `interface-system` | CRT、掌机、窗口、角色选择屏等界面是核心审美元素 | 有条件推荐 |
| `analysis-board` | 主图、局部窗、连接线、标注点、刻度和图例共同形成解释结构 | 默认不推荐 |

`analysis-board` 仅在用户明确需要图鉴、说明书、档案或科技分析感时进入候选池。普通服装图案生产应先去除连接线、标注点、刻度、图例、编号和说明性局部窗，再归入 `artwork`、`emblem` 或 `panel-sequence`。

## 3. 视觉实现轴

分开记录三个维度：

- `renderingMedium`：版画、孔版、刺绣、针毡、陶瓷、黏土、水彩、漫画线稿、像素、剪纸、霓虹线描等成像媒介。
- `subjectForm`：保持原形、玩偶化、黏土化、毛毡化、像素角色化等主体形态变化。
- `visualSystem`：无、CRT、掌机、街机、档案卡、博物图录等固定视觉系统。

这些字段可以组合。例：`designProduct=artwork`、`renderingMedium=embroidery`、`subjectForm=preserve`；或 `designProduct=interface-system`、`renderingMedium=pixel`、`subjectForm=pixel-character`、`visualSystem=arcade`。

## 4. 版式结构轴 `layoutStructure`

| 值 | 说明 |
| --- | --- |
| `single-scene` | 单一连续画面 |
| `cutout-subject` | 主体抠出并置于简洁底面 |
| `badge-or-sticker` | 边界明确的集中图案 |
| `repeat-pattern` | 重复平铺 |
| `narrative-panels` | 分格服务于叙事或审美节奏 |
| `decorative-collage` | 拼贴模块服务于整体装饰，不解释局部 |
| `ui-windows` | 窗口、面板、控件是模板固定结构 |
| `annotated-callouts` | 局部放大、连接线、标注点、刻度或图例承担解释功能 |

`annotated-callouts` 是服装印制风险信号。出现下列任一组合时默认判为分析板：主图与局部窗之间有连接线；圆点或方框定位细节；色块充当图例；刻度、编号或伪标签解释主体。

## 5. 印制适配轴 `printReadiness`

| 等级 | 门槛 | 处理 |
| --- | --- | --- |
| `A` | 一眼像完整图案；无分析标注；主体清晰；缩小后仍成立 | 可直接进入效果测试 |
| `B` | 图案成立，存在可接受的分格、边框或界面结构 | 标记结构型模板并继续测试 |
| `C` | 风格有价值，分析线、标注窗、仪表或容器抢占视觉 | 去结构化后重编译再测 |
| `D` | 核心机制弱、摄影残留、主体漂移、画幅错误或整体不适合印制 | 淘汰或重新设计 |

按以下顺序判定：

1. **图案性**：缩略到胸前印花尺度时仍能快速识别主体和整体造型。
2. **主体性**：分析组件、界面外壳和空白不会压过用户主体。
3. **印制简洁度**：连接线、细刻度、伪文字和小图例不依赖屏幕阅读。
4. **边界完整性**：设计拥有可理解的外轮廓、满版边界或连续画面。
5. **生产稳定性**：主体特征、实例、关系、非摄影覆盖和源画幅符合契约。

## 6. 模板编译路由

默认路由：

- 参考素材以画风、纹理、笔触和色彩为价值中心：产出 `artwork` 或 `emblem`。
- 分格本身具有漫画叙事或节奏价值：产出 `panel-sequence`，格内不加解释线。
- UI 或设备界面具有明确潮流审美价值：产出 `interface-system`，控制窗口数量和主体占比。
- 参考素材含分析图语言，但用户未明确要求分析感：执行“去结构化编译”。保留媒介、色彩、纹理和主体重绘，移除连接线、标注点、刻度、图例、编号、局部说明窗和仪表。
- 用户明确要求档案、图鉴、分析或说明书：允许 `analysis-board`，同时标记 `printReadiness=B/C` 并单独测试小尺寸可读性。

## 7. 提示词约束

普通服装图案模板在结构段使用正向目标：

```text
成图是一幅可直接用于服装印制的完整图案。主体与装饰形成连续视觉整体；画面只保留具有审美作用的边框、分格或底纹。局部细节通过笔触、色块、纹理和层次直接表现。
```

必要硬边界：

```text
连接线、定位点、分析框、刻度、图例、编号、仪表和说明性局部放大窗均不进入结果。
```

结构型模板获得例外权限时，逐项列出允许保留的结构及数量；未获授权的分析组件继续排除。

## 8. 验收

在原六维评分之外增加印制适配门：

- `printReadiness=A/B` 才能成为普通模板 good case；
- 画面意外出现 `annotated-callouts` 时，即使媒介还原优秀，也判为 `needs-prompt-revision`；
- `analysis-board` 只有在模板意图明确且测试输入也验证通过时，才能成为结构专题模板；
- 人工业务判断优先于自动视觉评分，并作为下一轮分类与提示词修订的标注数据。
- 用户可见分类必须属于九类且唯一；公开标题必须为 3–6 个字符并在当前交付批次内唯一。
