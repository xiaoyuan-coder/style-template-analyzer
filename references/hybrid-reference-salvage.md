# 混合参考与低信息素材救援

当参考图依赖照片、滤镜、拼版或局部覆盖层时，提取可观察的视觉算子，并把算子扩展为完整非摄影成像。救援结果使用 `qualityStatus: salvaged`；它可以生成运行模板，真实生成测试通过前保持待验证状态。

## 1. 救援入口

命中任一情况时进入救援：

- 摄影像素承担主要形体，风格只表现为偏色、柔焦、颗粒或拖影；
- 照片上叠加点阵、字符、颜料、线稿或发光符号；
- 照片被切成模块、纸片或错位碎块；
- 素材接近纯黑、纯白或只含极少有效标记。

保留原 `referenceType`，另写 `extractionMode`：

- `hybrid-operator-salvage`：照片或版式仍提供三个以上可测算子；
- `low-information-salvage`：只能测得黑白占比、负空间、稀疏标记或极少色彩关系。

## 2. 算子账本

从参考图依次取证，至少记录三个算子；低信息素材至少两个：

1. **色彩算子**：有限色盘、色相映射、明度压缩、综合色偏与叠色关系。
2. **边缘算子**：阈值硬边、扩散软边、点阵轮廓、字符轮廓、错位边或方向拖边。
3. **纹理算子**：颗粒尺寸、点阵间距、字符栅格、纸纤维、颜料擦痕与覆盖率。
4. **空间算子**：方向性拉伸、碎片化、重影、层叠和负空间比例。只迁移机制，不复制参考布局。
5. **明暗算子**：色阶数量、高光扩散范围、阴影密度和黑白占比。
6. **结构算子**：浮窗、容器、分格、局部放大、数据面板和固定装饰的数量、层级与自适应排布。只在它们是可跨输入复用的视觉系统时进入变换契约。

每个算子必须能在参考图上指出像素证据，并能扩展到人物、宠物、物件和场景。

## 3. 非摄影载体

选择参考图中最强的非摄影标记作为全局载体：

| 参考信号 | 全局载体 |
| --- | --- |
| 胶片颗粒、偏色、柔焦 | 用颗粒簇和低频色面直接构造形体；高光变成奶白色面，摄影像素退出 |
| 字符或像素叠影 | 用同一字符/像素栅格重建全部主体和背景 |
| 点阵轮廓 | 用点阵密度、点列边缘和实色块共同构造全部区域 |
| 长曝光或方向拖影 | 用方向一致的刷带、色带和硬边残影重建形体 |
| 照片碎片拼版 | 每个碎片内部改用同一非摄影色面或网印纹理；碎片机制覆盖整图且不继承参考布局 |
| 彩绘覆盖层 | 把可见颜料笔触、色盘和边缘机制扩展到所有像素，参考手形、星星和文字只进入禁迁移清单 |
| 近乎纯黑或纯白 | 用主色占比、负空间和稀疏反色标记构造极值版画；轮廓必须保持用户内容可识别 |

载体描述必须落实到像素组织。使用“艺术化、氛围感、电影感”不足以构成救援。

## 4. 覆盖扩展

把参考图中的局部算子离线编译为覆盖主体、环境、模板固定结构、边缘和角落的重构规则。运行提示词同时说明：

- 主体集合、主体特征、主体关联物和关键关系保持不变；
- 只使用已取证的算子，不提参考图或参考案例物象；
- 全部形体由非摄影载体重新构造；
- 摄影底图、镜头光照、原始景深和原照片轮廓完全退出；
- 只有 `transformationContract` 明确授权的布局、浮窗、容器、装饰或其他固定结构进入结果；案例专属物象继续留在禁迁移清单。

## 5. 证据和状态

`salvagePlan` 保存：

- `sourceDependency`：原效果依赖照片、覆盖层、版式或近空素材的程度；
- `observedOperators`：可在参考图上直接测得的算子；
- `nonPhotographicCarrier`：算子如何转成完整非摄影像素；
- `coverageExpansion`：如何覆盖整张用户图；
- `uncertainty`：参考图没有直接提供、只能保守外推的部分。

救援模板的分析置信度通常低于直接风格参考。静态 Validator 通过只代表证据完整；最终仍需至少四类输入、每类 2–4 个候选和独立评分。若结果保留摄影底图，直接判为硬失败。
