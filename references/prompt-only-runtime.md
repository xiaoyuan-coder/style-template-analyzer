# Prompt-only 整图视觉重构运行协议

## 运行输入

生成适配器只向模型提交：

1. `inputSchema` 中 `id: source` 的用户上传图；
2. 已编译的 `promptTemplate`。

模型图片数组固定为 `[source]`。`cover`、`metadata.sourceRef.styleAsset`、分析素材和 good case 均不进入图片数组。

## 展示字段

当前研发 Schema 保留 `kind: STYLE_REF` 作为兼容分类，并使用 `cover` 提供前端封面或效果图。运行模板不保存 `referenceImage`；离线参考素材、分析证据和测试效果通过分析档案、评测记录、`artifact-manifest.json` 与生产目录追溯。`STYLE_REF` 可以承载所有已授权的整图视觉重构。

## 提示词角色

运行请求由 `[source] + promptTemplate` 组成，因此提示词使用“用户上传图”指向运行时图片。单图数量和私有性由 `inputSchema` 与运行适配器保证，无需在 prompt 里重复 API 合同。

新 revision 的提示词固定使用九个模型可读段落，完整规范见 `runtime-prompt-authoring-standard.md`：

1. `任务`：说明以用户上传图为内容依据，要生成什么类型的新图像。
2. `保留`：说明需持续可辨认的主体、身份、服装、关系、数量和其他输入不变量。
3. `变换权限`：直接说明可以改变的形态、动作、视角、环境、实例、裁切或构图。
4. `核心效果`：定义 1–3 个必现机关及其可见结果。
5. `空间结构`：说明画幅、区域、尺度、层级、遮挡、路径和边界。
6. `内容映射`：说明用户图内容如何进入各区域及核心角色如何替代。
7. `视觉风格`：用可视化的颜色、线条、材质、纹理和明暗定义目标成像。
8. `完成判据`：列出 3–5 个最终图必须同时满足的可观察条件。
9. `限制`：只列真实漂移风险，例如额外主体、可读文字或摄影像素。

这一结构参考 OpenAI 官方图像提示指南中的编辑原则：明确区分保持项和改变项，同时使用构图、背景与“不要额外元素”等硬约束限制漂移：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>。

合同字段名、证据摘要、“前文”、“复现边界”和“来源绑定”等内部语言只留在审计文件。运行 prompt 不使用内部分类名代替像素级描述。

Before/After 只参与离线编译和评测。运行提示词不能把 Before 中的具体人物、物种、道具或场景当作用户新图必须具备的内容；应将其抽象为主主体、主识别区域、关联轮廓、接触部位、承托面、方向线索或高光切点。模板保留相对布局、数量、节奏、材质转折和关系机制，实际几何从用户图可见内容重新求值。核心机关需要由必选角色或其替代角色承担；辅助角色可以省略。

风格型模板明确“仅改变绘制语言”。形态或结构化模板明确写出允许的新形态、新视角、新动作、重复呈现、环境重构、构图重组和固定结构。

## 画幅与尺寸

读取 `source` 的宽、高和宽高比后执行 `effect-reproduction-contract.json` 的画幅决定。默认继承源图；Approved After 明确授权时可以自适应重定或使用模板固定画幅。`imageSize` 只提供名义像素预算。生成服务只接受离散尺寸时，选择与合同方向和比例最接近的尺寸，并记录相对偏差。

## 内容边界

- 默认保留所有显著主体；`primary-subject` 模板可以忽略次要主体和环境路人。
- `instanceMode: preserve` 保持原主体与基础实例逐一对应，人物、动物、物体及关联物不复制、不合并、不删减、不增殖。
- `instanceMode: repeat-or-split` 允许同一主体重复、分格、局部放大、新视角和新动作；每个派生实例需要可追溯到原主体，不形成新的独立主体。
- 环境可以按契约改变；服装、配饰、手持物和其他主体关联物跟随主体保留。
- 模板授权常量可以新增；参考案例主体与未授权物象不进入输出。
- 用户主体上的可识别文字或标识属于主体特征；环境文字可以随环境重构移除。通用契约不添加固定品牌文字。

## 验收硬失败

- 运行请求包含 `cover` 或其他离线参考素材；
- 显著主体丢失、身份替换、基础主体实例复制/合并/删减/增殖，或派生实例形成新独立主体；
- 主体特征漂移，包含发型、服装、配饰或手持物丢失或串用；
- 参考案例物象或其他越权内容出现；
- 任意可辨认摄影区域残留；
- 输出方向或宽高比明显偏离复现合同；
- 关键标志性变换机制完全缺失。

姿态、视角、呈现实例、环境或构图发生契约已授权的变化时，不计为硬失败。
