# 模板自生产设计与直接视觉评审

本规范用于 `produce` 的候选设计和用户审批阶段。目标是让每个新模板同时拥有可辨识的图形语言和可迁移的构图结构，并在正式编译、测试图入账和 OSS 上传前尽早淘汰弱方向。

## 1. 用 X + Y 定义候选

每个候选必须明确声明两个主维度：

- `X = graphicLanguage`：决定画面如何被绘制，例如硬边平涂、粗轮廓、双色正负形、网点漫画、阈值版印。
- `Y = spatialGrammar`：决定内容如何被重新组织，例如闭环放射、负形嵌套、前中后景舞台、剪影容器、非等分拼接。

X 与 Y 都必须明显改变最终像素。配色替换、颗粒、纸纹、金属感、线宽微调、外加边框或普通背景不单独算 Y；只替换材质但沿用同一布局也不形成新候选。

默认生产印制模板时，材质只作为辅助表现。只有用户明确需要实体材料形态，且适用场景足够广时，才把黏土、金属、钩织、压印等设为主 X。印刷油墨可以模拟网点、排线和有限色阶，不把工艺制作感当作模板价值中心。

## 2. 结构创新门槛

提出候选前先回答：

1. 用户内容被放到哪里？
2. 主体之间的关系怎样被 Y 重组？
3. 去掉 X 后，Y 是否仍能从缩略图上被识别？
4. 换成另一类真实输入，Y 是否仍成立？

CRT、街机、窗口等界面只是一类 Y。不得把“固定外壳 + 中央主体 + 周边小模块”反复换皮后当作多种结构。允许从来源关系中发明新的结构语法；同批候选应覆盖多个 Y 家族。

批次门槛：

- 每个候选都有一项主 X 和一项主 Y；
- 六个候选至少覆盖三个明显不同的 Y 家族；五个候选仍至少覆盖三个；
- 同一 Y 家族最多保留两个候选，且两者必须通过不同的信息组织关系成立；
- 仅有 X、Y 弱到近似普通角色插画、或本质复用同一结构的候选，在付费生成前淘汰。

## 3. 印制完整性硬门槛

`artwork` 和 `emblem` 默认生成完整图案或完整形状：

- 外轮廓连续闭合，主体、结构载体、底座和关键装饰完整可见；
- 四周保留约 8%–12% 安全边距；
- 显著主体不得拦腰裁切、贴边截断、被内部结构吞并或只剩难以辨认的碎片；
- 嵌套结构中的每个内层主体必须独立、完整、可辨识；
- 舞台结构必须同时收住前景门槛、左右侧翼、主台和后景，避免像从大图中裁下一段；
- 只有明确的满版 `pattern` 才允许触边；触边不能切断人物、动物、物体等语义主体。

把这些要求写入候选 prompt。封面轻量检查发现意外裁切或外轮廓未收口时直接 retry；第二次仍失败则拒绝该 revision。

## 4. 直接生产再评审

当用户需要判断效果时，直接生成候选效果图。抽象线框、文字示意或同构草图只作为内部推演证据，不作为主要审批界面。

直接评审按以下顺序进行：

1. **Y 是否成立**：缩略图能否看出放射、嵌套、舞台等结构关系。
2. **形状是否完整**：是否存在拦腰裁切、贴边或结构被画布截断。
3. **X 是否明确**：平涂、粗线、双色负形、网点等图形语言是否稳定。
4. **跨输入泛化**：更换人物、物件、场景后是否仍能形成同一模板。
5. **印制适配**：缩小后是否仍像完整图案，细节是否依赖屏幕阅读或实体工艺。

测试图本身若审美质量差、主体状态怪异或干扰结构判断，立即更换测试图，并把该资产退出当前 ready 选择；保留审查证据，避免在其他模板继续复用。不能用“模板结构正确”抵消难看的封面测试图。

## 5. 批准与编译

- 保存用户批准的候选序号、工作标题、边界规则和明确淘汰项。
- 只编译批准项；被淘汰候选不得进入模板包、测试图正式分配或 OSS 最终化。
- 用户要求修改完整性时，先修正直接效果图并再次获得批准，再编译 prompt。
- 编译时把 X、Y、完整性和越权边界写进 `promptTemplate`；不能依赖审批图作为运行时输入。
- 最终包继续执行基线新颖性、唯一测试图、OSS 回填和严格双文件校验。

## 6. 候选审计清单

进入正式编译前逐项确认：

- [ ] 主 X 是可迁移的图形语言，材质没有无意占据主轴。
- [ ] 主 Y 是内容组织关系，能够独立于 X 被看见。
- [ ] 当前批次没有用同一结构骨架反复换皮。
- [ ] 直接效果图已经生成，用户能够按真实视觉结果判断。
- [ ] 图案或形状完整，未出现拦腰裁切和意外触边。
- [ ] 测试图适合展示模板，不会因自身难看干扰评审。
- [ ] 用户批准项与淘汰项已有可追溯记录。
