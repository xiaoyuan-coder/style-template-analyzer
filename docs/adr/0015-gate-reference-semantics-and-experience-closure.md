# ADR 0015：把参考语义、独立视觉比较与经验沉淀纳入主事务

- 状态：Accepted
- 日期：2026-08-20

## 背景

近期多轮风格模板生产重复出现四类问题：成对 before/after 参考图被按完整版式复制；标题、色条和套准线等解释性元素进入模板常量；生产者依据自己的分析给自己的结果放行；人工 GoodCase/BadCase 结论未稳定进入下一轮经验快照。零散批次脚本还绕过了测试图预留、来源绑定和 OSS 配置发现。

原有 schema 能验证文件形状与身份，却无法证明参考图被正确理解，也无法证明视觉结果由独立观察者比较。经验 adapter 采用可选旁路，使生产成功与组织学习长期分离。

## 决策

1. 参考编译在测试图预留前必须生成并校验 `reference-interpretation.json`。成对参考明确 `before` 与 `target-effect`；对比/标注图明确解释性区域与排除项；未消解歧义直接阻断。
2. 封面技术检查通过后，由未参与分析和 prompt 编写的 reviewer 生成 `reference-visual-gate-receipt.json`。六维单项最低 80、平均最低 90；解释性布局复制属于硬失败。
3. `pass/reject` 必须完成经验账本幂等写入并生成 `experience-deposit-receipt.json`。写入失败时保留人工结论用于重试，同时阻断 OSS 正式化。
4. 自生产只接受与经验语料 SHA-256 一致的 `current.json`。缺失、损坏或过期快照停止新生产。
5. 日常命令统一收敛到 `style_workflow_cli.py`。封面生成前先执行 `reserve-test-image`；编译阶段核对生成回执中的 `sourceAssetId`。
6. OSS 环境变量沿输入路径向上发现 `.env`，运行时环境变量拥有最高优先级，日志不输出密钥值。
7. artifact manifest 升级到 5.0.0。4.0.0 包继续只读校验；新参考编译包不得用旧包幂等短路新门禁。

## 结果

- 参考图含义成为独立、可审核的前置事实，错误解释不会消耗测试图。
- 视觉验收拥有独立证据和明确阈值，schema 合法无法替代视觉相似度。
- 人工结论与经验更新形成可恢复闭环，下一轮生产可以证明自己读取了最新经验。
- 测试图预留、封面来源、审核状态与正式化继续由同一 revision 身份串联。

代价是生产多出两个门禁产物和一次经验写入。经验服务暂时不可用时，人工结论会停留在可重试状态，正式包需要等待经验恢复。
