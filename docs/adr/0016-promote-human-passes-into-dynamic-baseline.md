# ADR 0016：人工通过自动进入动态基线

- 状态：Accepted
- 日期：2026-08-20
- 取代：ADR 0011 中“人工通过后仍需独立基线批准”的默认规则

## 背景

静态 94 条基线与实际人工通过目录逐渐分离，导致后续自生产无法及时看到已经确认的模板。用户明确要求基线随自己的通过决定动态增加。

## 决策

1. 人工 `pass` 是动态基线的唯一晋升触发器，无需额外基线批准动作。
2. 全部历史已确认通过模板作为动态基线起点。当前统一通过目录包含 144 个有效 key。
3. 同 key 可以保留多个通过 revision；自生产只激活 revision 数字最大的版本，旧 revision 继续保留审核与回滚证据。
4. `review-decision pass` 在经验沉淀后幂等登记统一通过目录，并写入 `dynamic-baseline-registration-receipt.json`。登记失败时保留可重试的人工决定，OSS 正式化继续等待。
5. 自生产默认读取 `references/dynamic-baseline.json` 指向的统一目录，不再读取 94 条静态批准描述。旧描述改名为 `legacy-approved-baseline-94.json`，只服务 v3/v4 兼容回归。
6. 动态基线快照继续冻结成员路径与 SHA-256，使单次生产可追溯到当时实际读取的成员集合。

## 结果

用户通过的新模板会立即参与后续查重、新颖性和机制覆盖判断。新增 key 会增加当前基线数量；同 key 新 revision 会替换当前有效版本，成员数量保持不变。
