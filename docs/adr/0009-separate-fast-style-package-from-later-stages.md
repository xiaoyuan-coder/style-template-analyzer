# 拆分模板生产、OSS 最终化与真图评测

风格化模板先生成模板草稿和本地封面，通过轻量封面检查后形成待发布模板产物。轻量检查只拦截图片不可读、模板效果基本未体现、主体严重损坏、明显异常文字或水印；同一测试图最多生成两次。仍未通过的 revision 保存内部草稿、生成回执和原因并进入失败终态，不进入 OSS。基础设施故障允许原 revision 恢复，模板或画面问题需要修正后创建新 revision。

模板包必须经过 OSS 最终化：上传封面、回填正式图片地址、执行最终契约校验，然后写出只包含最终 `style-template.json` 和封面图的交付目录。真图评测保持为后续独立阶段，不阻塞模板包。批量生产按模板独立完成，成功包可以先交付，失败项返回明确原因。这项拆分移除了拿包前耗时的完整评测，同时保证模板包内的数据已经最终化。
